# Story 0.5 — Profile view and update
Points: 3 | Tool: executing-plans | ADRs: 001, 014

As the owner, I want to see and edit my profile.

Acceptance criteria
- [ ] Profile page shows username, display name, account creation date, current stage.
- [ ] Display name is editable.
- [ ] Password change requires the current password and a new password of at least 8 characters.
- [ ] Keyboard layout preference is shown as HU_QWERTZ and is read-only in v1.
- [ ] Interface language is English only in v1 (OQ-2).
