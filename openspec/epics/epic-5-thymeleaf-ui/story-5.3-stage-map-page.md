# Story 5.3 — Stage map page
Points: 5 | Tool: executing-plans | ADRs: 013, 002

Acceptance criteria
- [ ] Shows the five stages with status: LOCKED, UNLOCKED, SUB_EXAMS_PASSED, GRADUATED.

- [ ] Graduation button shown only when eligible (Story 2.3).
