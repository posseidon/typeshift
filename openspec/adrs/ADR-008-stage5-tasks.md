# ADR-008: Stage 5 randomised real-world tasks
Status: Locked

**Decision**
- Each Stage 5 sub-exam presents one task drawn at random from: CHAT_BURST, EMAIL_REPLY, DOCUMENT_PARAGRAPH, CODE_COMMENT.
- The orchestrator avoids repeating the same task type on consecutive attempts.
- Content is generated by the Prose agent with taskType as a parameter.
- Graduation test: three task types drawn in sequence within one session. All three must pass.
- Tasks run one after another, never simultaneously.
