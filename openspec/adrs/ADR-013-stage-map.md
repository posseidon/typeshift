# ADR-013: Stage map (authoritative)
Status: Locked

| Stage | Name | Focus | Sub-exams | Graduation |
|---|---|---|---|---|
| 1 | QWERTZ Core | Home row, top row, bottom row including Z and Y | 3 | 3-minute continuous QWERTZ passage |
| 2 | Symbol Sorcerer | Punctuation, symbols, brackets | 2 | Formatted technical support ticket |
| 3 | Numpad and Math | 10-key entry, ledger equations | 2 | Cashier Rush math evaluation |
| 4 | Hungarian Accents | á é í ó ö ő ú ü ű and related | 2 | Formal Hungarian request letter |
| 5 | Real-World Tasks | Chat, email, document, code comment | 4 | Three random tasks in sequence (ADR-008) |

Pass threshold for every sub-exam and graduation test: accuracy at or above 95% (ADR-016). Stage 3 numeric results must be 100% correct.
