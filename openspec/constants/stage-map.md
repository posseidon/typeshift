# Stage map
Authoritative stage definition. Mirrors ADR-013.

| Stage | Name | Sub-exams | Graduation test |
|---|---|---|---|
| 1 | QWERTZ Core | 3 | 3-minute QWERTZ passage |
| 2 | Symbol Sorcerer | 2 | Technical support ticket |
| 3 | Numpad and Math | 2 | Cashier Rush |
| 4 | Hungarian Accents | 2 | Formal Hungarian request letter |
| 5 | Real-World Tasks | 4 | Three random tasks in sequence |

Pass rule: accuracy >= 0.95 (ADR-016). Stage 3 numeric answers: exact match.
Unlock rule: Stage N+1 unlocks when all sub-exams of Stage N are passed (see Epic 2, open question OQ-1).
