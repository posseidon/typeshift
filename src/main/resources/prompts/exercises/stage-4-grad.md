# Formal Hungarian request letter

Write a complete formal Hungarian request letter in clear B1-level Hungarian. Use a fictional everyday public-office situation, such as a resident asking for help with a community service. State the request and one simple reason without saying it was approved or completed. Include a polite greeting and respectful closing. Use at least six distinct letters from `á é í ó ö ő ú ü ű` naturally and preserve every accent. Keep it 300–450 characters.
