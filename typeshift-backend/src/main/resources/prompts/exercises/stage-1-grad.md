# 3-minute continuous QWERTZ passage

Write a clear B1-level Hungarian 3-minute continuous QWERTZ passage. Tell one engaging everyday story: a family is preparing for a local event, a small problem appears, and they solve it together. Include concrete details and natural dialogue where it fits. Write 1,000–4,000 characters; use home, top, and bottom-row keys—including Hungarian accents—naturally. No heading, bullets, key list, or separate drills.
